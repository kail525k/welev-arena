# WELEV ARENA — 경찰특공대 협동 웹 FPS

브라우저에서 바로 하는 경찰특공대 총싸움 체험판이에요.

- 게임은 `index.html` 파일 하나로 돌아가요 (three.js, supabase-js는 CDN에서 불러와요).
- `models/`·`guns/`는 캐릭터·총 3D 모델(glb를 base64로 담은 json)이에요.
- 같이하기(무한 작전)는 Supabase(welev-games) Realtime으로 입장·연결 신호를 주고받고, 움직임·사격은 대원끼리 WebRTC로 직접 주고받아요.
- Vercel에서 이 저장소를 가져오면 별도 설정 없이 배포돼요. 프레임워크는 "Other".

## 같이하기 — 무한 작전
- 메뉴의 **같이하기 · 무한 작전** → 이름 적고 맵 고르기 → 출동. 사람이 있는 방에 자동으로 들어가요(한 방 16명, 차면 다음 방).
- 초대 링크: `https://welev-arena.vercel.app/?room=yeongtong-1` 처럼 방 이름이 붙어요(일시정지 메뉴에서 복사).
- 방장(지휘) 1명이 강도·시민 AI와 위협 단계·팀 점수를 돌리고, 나가거나 탭을 내리면 다른 대원이 이어받아요.
- 75초마다 위협 단계가 오르고, 대원 수·단계에 따라 동시에 나오는 강도 수가 늘어요(최대 22명). 4단계마다 두목.
- 시험: `?net=local`을 붙이면 Supabase 대신 같은 브라우저 탭끼리(BroadcastChannel) 연결돼요. `&nodc=1`은 직접 연결 없이 중계만.
